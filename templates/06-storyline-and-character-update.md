# 子技能6：故事线与人物线更新

## 技能概述
自动更新世界观文档和伏笔追踪

## 适用场景
正文定稿后，备份前调用

## 输入格式
- 定稿的正文文本
- 本章剧情推演报告
- 前文状态报告

## 输出格式
更新后的以下文档：
- 人物状态表
- 伏笔追踪表
- 章节梗概文档
- 世界观设定（如有变化）

## 执行步骤

### 1. 更新人物状态表
读取`设定文档/人物状态表.md`，更新：

**每个出场人物需更新**：
- **当前位置**：本章结尾时在哪里
- **身体状态**：是否受伤、疲劳等
- **心理状态**：情绪变化、认知变化
- **人际关系**：与其他人物的关系变化
- **持有物品**：获得、丢失、使用物品
- **知晓信息**：新获得的信息或线索

**更新示例**：
```
【人物状态表 - 更新后】

张三：
• 位置：家中
• 身体：正常
• 心理：对项链的好奇 > 恐惧，对李明半信半疑 > 信任
• 关系：与李明建立初步信任；其他同学关系不变
• 物品：持有项链（已发现会发光）
• 信息：知晓"光影"存在；知晓李明也见过光影；获得半本日记
```

### 2. 更新伏笔追踪表
读取`设定文档/伏笔追踪表.md`，更新：

**新埋设的伏笔**：
- 分配伏笔编号（F-XXX，自动递增）
- 记录埋设章节
- 记录伏笔内容
- 预估回收章节（可模糊，如“第10章左右”）

**已回收的伏笔**：
- 标记“已回收”
- 记录回收章节
- 记录回收方式

**伏笔状态示例**：
```
【伏笔追踪表 - 第5章更新后】

F-001: 神秘短信的来源
  埋设：第1章
  状态：未回收
  预计：第8章

F-002: 项链的真正能力
  埋设：第2章
  状态：✅ 已回收（第5章）
  回收方式：张三测试项链，发现能看见光影

F-004: 半本日记的来源（新埋设）
  埋设：第5章
  内容：日记是谁的？为什么只有半本？
  状态：未回收
  预计：第12章左右

F-005: 符号与主角的关系（新埋设）
  埋设：第5章
  内容：章末揭示符号与主角童年记忆有关
  状态：未回收
  预计：第15章左右
```

### 3. 更新章节梗概文档
在`大纲细纲/章节梗概.md`中追加本章梗概：

**格式**：
```
第X章：（章节标题，如有）
- 字数：XXXX字
- 核心事件：一句话概括
- 关键转折：发生了什么意外
- 人物变化：哪些人物有成长或变化
- 伏笔：埋设/回收了哪些伏笔
```

**示例**：
```
第5章：秘密房间的发现
- 字数：2034字
- 核心事件：张三测试项链能力，追光影到旧校舍秘密房间，找到半本日记
- 关键转折：发现日记最后一页的符号与童年记忆有关
- 人物变化：张三对项链从恐惧到好奇；与李明建立初步信任
- 伏笔：回收F-002；埋设F-004、F-005
```

### 4. 更新世界观设定（如有变化）
如本章引入了新的设定，更新`设定文档/世界观设定.md`：

**可能的变化**：
- 新地点（如秘密房间）
- 新规则（如项链的能力）
- 新组织（如发现日记属于某个组织）
- 力量体系补充

**更新原则**：
- 不颠覆前文设定
- 新设定要与前文铺垫呼应
- 记录设定引入的章节

### 5. 生成更新报告
汇总所有更新：
```
【故事线更新报告 - 第5章】

== 人物状态更新 ==
• 张三：心理变化，持有物品更新
• 李明：无变化

== 伏笔追踪更新 ==
• 回收：F-002
• 新增：F-004、F-005

== 章节梗概 ==
已追加第5章梗概

== 世界观更新 ==
• 新增地点：旧校舍秘密房间
• 新增设定：项链可看见"光影"
```

## 注意事项
- 严格根据正文内容更新，不添加未发生的内容
- 伏笔编号要唯一，不能重复
- 人物状态更新要全面，不要遗漏次要人物
- 如本章没有新伏笔，也要明确说明“本章无新伏笔”

## 调用示例

**输入**：
```
更新第5章的故事线和人物线
```

**输出**：
```
已更新相关文档：

✅ 人物状态表 - 更新了张三的状态
✅ 伏笔追踪表 - 回收1个，新增2个
✅ 章节梗概 - 追加第5章梗概
✅ 世界观设定 - 新增"秘密房间"地点

是否进入自动备份步骤？
```
