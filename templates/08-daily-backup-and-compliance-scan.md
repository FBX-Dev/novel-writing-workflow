# 自动化技能：每日存稿备份与合规扫描

## 技能概述
每次自动备份+扫描敏感词和违规风险

## 适用场景
- 每日创作结束后自动触发
- 可配置为定时任务（如每天23:59自动运行）
- 手动调用（如需即时备份）

## 输入格式
- 项目目录路径
- 当日创作的所有章节

## 输出格式
- 备份完成报告
- 合规扫描报告
- 风险预警（如有）

## 执行步骤

### 1. 收集当日创作
- 扫描`正文存稿/`目录
- 识别当日修改/新增的章节
- 生成当日创作清单

### 2. 执行增量备份
对每个当日有修改的章节：
- 检查是否已有当日备份
- 如无，执行备份（调用子技能7）
- 如有，比对内容，如有变化则创建新版本

备份策略：
```
每日23:59自动备份
↓
检查当日是否有新创作
↓
如有，执行增量备份
↓
如连续3天无新创作，发送提醒
```

### 3. 合规扫描
对当日创作的章节进行合规扫描：

**扫描项目**：
- ✅ 违禁词检测
- ✅ 敏感内容检测（政治、色情、暴力）
- ✅ 价值观导向检测
- ✅ 平台规则合规性

**违禁词库**：
- 基础库：`技能配置/违禁词库.txt`
- 平台库：`技能配置/平台规则/[平台名]_违禁词.txt`

**扫描输出**：
```
【合规扫描报告 - 2025-06-22】

扫描章节：第5章

== 违禁词检测 ==
• 未发现违禁词

== 敏感内容检测 ==
• 未发现敏感内容

== 价值观导向 ==
• 导向正常

== 平台规则合规性 ==
• 符合起点中文网规则

✅ 合规通过
```

### 4. 风险预警
如发现风险，生成预警报告：

**风险等级**：
- 🟢 低风险：个别违禁词，可自动替换
- 🟡 中风险：敏感内容，需人工审核
- 🔴 高风险：严重违规，立即停止发布

**预警输出**：
```
【风险预警 - 2025-06-22】

⚠️ 发现中风险问题

章节：第5章
问题：第8段描写可能涉及暴力细节
原文："...血溅了一地，场面十分血腥..."

建议：
1. 淡化暴力描写，改为暗示
2. 或删除该段落

是否自动修改？[是/否/人工审核]
```

### 5. 生成每日报告
汇总备份和扫描结果：
```
【每日备份与扫描报告 - 2025-06-22】

== 备份情况 ==
• 备份章节：第5章
• 版本号：v250622-2359
• 状态：✅ 成功

== 合规扫描 ==
• 扫描章节：第5章
• 结果：✅ 合规通过

== 风险提示 ==
• 无风险

== 创作统计 ==
• 今日创作：1章
• 累计创作：5章
• 累计字数：10,023字
```

### 6. 发送通知（可选）
如配置了通知方式，发送通知：
- 企业微信通知
- 邮件通知
- 桌面通知

通知内容：
```
📝 每日备份完成

今日创作：第5章（2034字）
累计创作：5章（10,023字）
合规状态：✅ 通过
```

## 配置说明

### 定时任务配置
在WorkBuddy中配置自动化任务：
```
任务名称：每日小说备份与扫描
触发时间：每天 23:59
执行技能：自动化技能-每日存稿备份与合规扫描
项目路径：[你的小说项目路径]
```

### 合规规则配置
在`技能配置/`目录下维护：
- `违禁词库.txt` - 基础违禁词
- `平台规则/` - 各平台审核规则
- `风险等级设置.json` - 风险等级判定规则

### 通知配置
在`技能配置/notification_config.json`中配置：
```json
{
  "enabled": true,
  "method": "wecom",  // wecom/email/desktop
  "notify_on": {
    "backup_success": true,
    "compliance_fail": true,
    "risk_warning": true
  }
}
```

## 注意事项
- 每日自动备份不影响手动备份
- 如发现高风险问题，立即暂停发布流程
- 定期更新违禁词库（跟随平台规则变化）
- 保留所有扫描记录，方便追溯

## 调用示例

**自动触发**（定时任务）：
```
（每天23:59自动运行）

> 执行每日备份与扫描...
> 发现今日创作：第5章
> 执行备份...
> 执行合规扫描...
> 生成报告...
> 发送通知...
✅ 每日任务完成
```

**手动调用**：
```
立即执行备份与扫描
```

**输出**：
```
已完成备份与扫描。

今日创作：第5章
备份版本：v250622-1430
合规状态：✅ 通过
无风险预警

是否查看详细报告？
```
