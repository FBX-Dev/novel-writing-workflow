# 子技能7：自动版本备份

## 技能概述
每章存档，保留完整版本历史

## 适用场景
正文定稿、故事线更新完成后调用

## 输入格式
- 章节号
- 定稿的正文文本
- 更新后的追踪文档

## 输出格式
- 备份完成确认
- 备份文件路径
- 版本号

## 执行步骤

### 1. 生成版本号
版本号格式：`vYYMMDD-HHMM`（年月日-时分）

例如：`v250622-1430`（2025年6月22日14:30）

### 2. 创建章节备份
在`版本备份/`目录下创建：
```
版本备份/
├── 第001章/
│   ├── 第001章_v250622-1430.txt
│   ├── 第001章_v250622-1500.txt（如有修改）
│   └── metadata.json
├── 第002章/
│   └── ...
```

**正文文件内容**：
- 纯文本格式
- 包含章节号（标题）
- 包含正文内容
- 不包含追踪文档

### 3. 创建元数据文件
每个版本附带`metadata.json`：
```json
{
  "chapter": 5,
  "version": "v250622-1430",
  "word_count": 2034,
  "backup_time": "2025-06-22 14:30:00",
  "status": "定稿",
  "changes": "初稿",
  "reviewer": "AI审查+人工确认"
}
```

如有修改，追加记录：
```json
{
  "chapter": 5,
  "version": "v250622-1500",
  "word_count": 2045,
  "backup_time": "2025-06-22 15:00:00",
  "status": "定稿",
  "changes": "根据审查报告修改第3段对话和第8段物品矛盾",
  "reviewer": "AI审查+人工确认"
}
```

### 4. 备份追踪文档
将更新后的追踪文档复制到版本文件夹（可选）：
```
版本备份/第005章/
├── 正文_v250622-1430.txt
├── metadata.json
└── 追踪文档/
    ├── 人物状态表_v5.md
    ├── 伏笔追踪表_v5.md
    └── 章节梗概_v5.md
```

### 5. 更新备份索引
在`版本备份/backup_index.md`中追加记录：
```markdown
# 备份索引

## 第5章
- v250622-1430（定稿）✅
  - 字数：2034
  - 时间：2025-06-22 14:30:00
  - 状态：已发布
  - 路径：`第005章/第005章_v250622-1430.txt`

## 第4章
- v250622-1200（定稿）✅
  - 字数：1987
  - 时间：2025-06-22 12:00:00
  - 状态：已发布
```

### 6. 生成备份报告
```
【备份完成报告 - 第5章】

== 备份信息 ==
• 章节：第5章
• 版本号：v250622-1430
• 字数：2034字
• 备份时间：2025-06-22 14:30:00

== 备份文件 ==
• 正文：`版本备份/第005章/第005章_v250622-1430.txt`
• 元数据：`版本备份/第005章/metadata.json`
• 追踪文档：`版本备份/第005章/追踪文档/`

== 索引更新 ==
已更新 `版本备份/backup_index.md`

✅ 备份完成
```

## 备份策略

### 何时备份
- ✅ 每章定稿后（必须）
- ✅ 重大修改后（如改写了整段剧情）
- ❌ 微小修改（如改了几个错别字）可不备份新版本

### 保留策略
- **保留所有版本**：方便回滚
- **定期清理**：如空间不足，可只保留最近3个版本+定稿版本

### 版本对比
如需查看版本差异，对比两个版本的`metadata.json`中的`changes`字段

## 注意事项
- 备份前确认正文已定稿
- 版本号必须唯一，不能覆盖
- 如备份失败，立即停止并报告
- 定期检查备份完整性

## 调用示例

**输入**：
```
备份第5章定稿
```

**输出**：
```
【备份完成报告 - 第5章】

版本号：v250622-1430
字数：2034字
备份路径：`版本备份/第005章/`

✅ 第5章备份完成

== 下一步 ==
是否将正文移至"正文存稿"文件夹并发布？
```
