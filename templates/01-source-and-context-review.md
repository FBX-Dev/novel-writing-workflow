# 子技能1：资料整理与前文梳理

## 技能概述
自动整理前文剧情、人物状态、未回收伏笔

## 适用场景
每次创作新章节前调用，作为7步循环的第一步

## 输入格式
- 当前章节号
- 项目目录路径

## 输出格式
结构化前文状态报告，包含：
- 人物状态摘要
- 前文剧情梗概（最近3-5章）
- 未回收伏笔清单
- 当前世界观状态

## 执行步骤

### 1. 读取人物状态表
- 从`设定文档/人物状态表.md`读取
- 提取主要人物的：
  - 当前位置
  - 当前状态（身体/心理/关系）
  - 持有物品
  - 未完成任务
  - 性格特征（用于后续OOC检查）

### 2. 读取前文梗概
- 从`大纲细纲/章节梗概.md`读取
- 提取最近3-5章的：
  - 章节号
  - 核心事件
  - 关键对话
  - 重要转折

### 3. 读取未回收伏笔清单
- 从`设定文档/伏笔追踪表.md`读取
- 列出所有状态为“未回收”的伏笔：
  - 伏笔编号
  - 埋设章节
  - 伏笔内容
  - 预计回收章节
  - 关联人物

### 4. 读取世界观设定
- 从`设定文档/世界观设定.md`读取
- 提取当前生效的：
  - 世界规则
  - 力量体系
  - 重要地点
  - 关键组织

### 5. 生成前文状态报告
整合以上信息，生成结构化报告

## 输出示例

```
【前文状态报告 - 第5章创作前】

== 人物状态 ==
• 主角-张三：体力恢复中，持有神秘项链，对李明半信半疑
• 配角-李明：新转学生，主动接近主角，身份成谜
• ...

== 前文梗概（第1-4章）==
• 第1章：主角收到神秘短信...
• 第2章：发现项链的奇怪能力...
• 第3章：李明转学进来...
• 第4章：两人在旧校舍探险...

== 未回收伏笔 ==
• [F-001] 神秘短信的来源（第1章埋设，预计第8章回收）
• [F-002] 项链的真正能力（第2章埋设，建议第5章回收）← 优先
• [F-003] 李明的真实身份（第3章埋设，预计第10章回收）

== 世界观状态 ==
• 当前地点：学校
• 当前时间：周三下午
• 特殊状态：旧校舍事件后，校园传闻扩散
```

## 注意事项
- 只读取和整理，不修改任何文档
- 如发现文档缺失，立即报告并请求补充
- 重点关注与本章创作相关的信息
- 伏笔清单按优先级排序（临近回收日期的优先）

## 调用示例

**输入**：
```
整理前文资料，准备创作第5章
```

**输出**：
```
已整理前文状态，发现第2章埋设的"项链能力"伏笔建议在本章回收。
是否在本章回收此伏笔？或继续推进主线？
```
