# 主技能：平台小说章节全流程创作

## 技能概述
统筹调用所有子技能，完成从资料到正文的完整流程

## 适用场景
每次需要创作新章节时调用

## 输入格式
- 章节号（如：第1章、第2章...）
- 本章大致方向或关键情节提示（可选）
- 特殊要求（如：需要回收某个伏笔、引入新角色等）

## 输出格式
- 正文内容（约2000字）
- 本章梗概（100字内）
- 更新后的人物状态
- 更新后的伏笔追踪表

## 执行步骤

### 步骤1：调用【资料整理与前文梳理】技能
- 读取人物状态表
- 读取前文梗概
- 读取未回收伏笔清单
- 读取世界观设定

### 步骤2：调用【单章剧情推演】技能
- 基于大纲和细纲
- 规划本章3-5个核心事件
- 确定本章冲突和节奏
- 标记需要回收的伏笔

### 步骤3：调用【平台标准正文生成】技能
- 按情节大纲生成正文
- 指定字数范围（约2000字）
- 内置去AI味处理
- 符合目标平台风格

### 步骤4：调用【合规与一致性审查】技能
- 检查人物对话是否符合性格设定
- 检查本章剧情是否与前文矛盾
- 检查平台规则合规性（违禁词/敏感描写）
- 输出结构化审查报告

### 步骤5：如有问题，调用【内容优化打磨】技能
- 针对性修改审查中发现的问题
- 优化对话自然度
- 增强画面感
- 调整章末钩子

### 步骤6：调用【故事线与人物线更新】技能
- 更新人物状态表
- 更新伏笔追踪表
- 更新章节梗概文档
- 更新世界观变化（如有）

### 步骤7：执行自动备份
- 保存当前章节至版本文件夹
- 保存更新后的追踪文档
- 记录元数据（创作时间、字数、关键情节等）

## 注意事项
- 不直接生成内容，只负责调度子技能
- 每步完成后确认无误再进入下一步
- 如遇问题立即暂停并报告
- 保持与用户的沟通，重要决策需人工确认

## 调用示例

**输入示例1**：
```
创作第1章
方向：主角清晨被神秘短信叫醒，发现手机群聊里同学们都在讨论昨晚的怪事
```

**输入示例2**：
```
创作第5章
要求：回收第2章埋下的"神秘项链"伏笔
引入新角色：转学生李明
```
