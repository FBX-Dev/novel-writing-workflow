# 子技能4：合规与一致性审查

## 技能概述
检查规则合规、人物OOC、剧情矛盾

## 适用场景
正文生成完成后调用，审查内容合规性

## 输入格式
- 本章正文文本（纯文本，无标题行）
- 人物设定文档
- 前文状态报告
- 平台审核规则

## 输出格式
审查报告，包含：
- 审查结论（合规/不通过）
- 问题清单（如有）
- 修改建议

## 执行步骤

### 1. 人物OOC检查
逐段检查人物对话和行为：
- **对话语气**是否符合人物性格？
- **行为动机**是否符合人物设定？
- **情绪反应**是否符合人物背景？

检查方法：
- 对比`设定文档/人物设定.md`中的性格描述
- 对比前文该人物的言行模式
- 标记任何“不像这个人会说的话”

**OOC判定标准**：
- 温和角色突然爆粗口（无特殊情境）
- 胆小角色突然胆大包天（无成长铺垫）
- 精明角色做明显蠢事（无特殊原因）
- 口音/说话习惯突然改变

### 2. 剧情矛盾检查
检查本章内容是否与前文矛盾：
- **时间线**是否连贯？
- **地点**是否一致？
- **人物状态**是否衔接？
- **物品持有**是否合理？
- **前文承诺**是否兑现？

检查要点：
- 前文说“某人不在场”，本章却出现
- 前文说“物品已丢失”，本章却又出现
- 前文说“某人性格内向”，本章却异常外向
- 时间跳跃无交代

### 3. 平台规则合规检查
根据目标平台审核规则检查：
- **政治敏感内容**
- **色情低俗描写**
- **暴力血腥细节**
- **违法违纪行为描写**
- **价值观导向问题**

常见问题：
- 过度描写暴力细节
- 性暗示描写
- 违法细节描写（制毒、 hacking等）
- 错误的价值观导向

### 4. 逻辑合理性检查
- 人物行为是否有足够动机？
- 巧合是否过多？
- 信息揭示是否合理？
- 能力设定是否前后一致？

### 5. 生成审查报告

**合规情况**：
```
【合规审查报告 - 第X章】

审查结论：✅ 合规通过

== 人物OOC检查 ==
• 所有人物对话和行为符合设定

== 剧情矛盾检查 ==
• 未发现与前文矛盾之处

== 平台规则合规 ==
• 符合起点中文网审核规则

== 逻辑合理性 ==
• 剧情推进合理，人物动机充分
```

**不通过情况**：
```
【合规审查报告 - 第X章】

审查结论：❌ 不通过，需修改

== 发现问题 ==

问题1：[OOC] 第3段
原文："你这个人真是烦死了！"
问题：张三性格温和，不会对同学说这种话
建议：改为"你能不能别跟着我..."

问题2：[剧情矛盾] 第8段
原文："张三从口袋里掏出那张照片"
问题：第3章写明照片已交给警察
建议：改为"张三想起那张照片"

问题3：[逻辑] 第12段
原文："他瞬间就想通了所有线索"
问题：线索过多，瞬间想通不合理
建议：增加思考过程，或改为"他隐约感觉到这些线索有关联"

== 修改建议 ==
建议调用【内容优化打磨】技能进行针对性修改
```

## 注意事项
- **不修改正文**，只输出审查意见
- 修改由人工或【内容优化打磨】技能执行
- 发现重大问题（如严重OOC、重大矛盾）应立即停止流程并报告
- 对于“灰色地带”的问题，标记出来由人工判断

## 审查标准参考

### OOC容忍度
- **轻微OOC**（语气小变化）：标记，建议修改
- **中度OOC**（性格有明显偏差）：判定不通过
- **严重OOC**（完全变成另一个人）：立即停止

### 剧情矛盾容忍度
- **轻微矛盾**（时间误差几分钟）：可忽略
- **中度矛盾**（物品/状态不一致）：判定不通过
- **严重矛盾**（颠覆前文重大设定）：立即停止

## 调用示例

**输入**：
```
审查第5章正文
平台：起点中文网
```

**输出**：
```
审查完成。
发现2个需要修改的问题：
1. 第3段对话有轻微OOC
2. 第8段出现物品矛盾

是否调用【内容优化打磨】技能进行修改？
```
