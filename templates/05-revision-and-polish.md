# 子技能5：内容优化打磨

## 技能概述
润色对话、增强画面感、调整节奏

## 适用场景
合规审查不通过，或人工要求优化时调用

## 输入格式
- 本章正文文本
- 审查报告（来自子技能4，如有）
- 优化要求（人工指定，可选）

## 输出格式
- 优化后的正文文本
- 修改说明（列出了哪些地方做了修改）

## 执行步骤

### 1. 分析审查报告（如有）
- 读取审查报告中标记的问题
- 按优先级排序（OOC > 剧情矛盾 > 逻辑问题 > 文笔问题）
- 针对性修改

### 2. 优化对话
检查每个对话段落：
- **是否符合人物性格**？（语气、用词、口头禅）
- **是否自然**？（避免书面化、说教式对话）
- **是否有信息量**？（推进剧情或展现人物）
- **是否冗长**？（精简无意义的客套话）

对话优化技巧：
```
❌ 不好的对话：
"张三，我告诉你，这个世界的真相是复杂的，我们需要勇敢地面对困难..."
（太书面化，没人这样说话）

✅ 好的对话：
"张三。"李明突然停下脚步，转过头，表情前所未有的严肃，"有些事，你还是别知道的好。"
（有动作，有情绪，有悬念）
```

### 3. 增强画面感
使用“展示而非讲述”原则：
```
❌ 讲述（Tell）：
张三很害怕。

✅ 展示（Show）：
张三的手指在微微发抖，他下意识地去摸口袋里的护身符。
```

增强画面感的方法：
- 用动作表现情绪
- 用环境烘托氛围
- 用感官描写（视觉、听觉、触觉等）
- 避免形容词堆砌，用具体细节

### 4. 调整节奏
- **快节奏段落**（冲突、动作、悬念）：短句、短段落
- **慢节奏段落**（抒情、思考、铺垫）：可适当用长句

节奏调整技巧：
```
❌ 节奏拖沓：
张三慢慢地走到了门口。他犹豫了一下。然后他推开了门。门发出吱呀的声音。他走了进去。

✅ 节奏紧凑：
张三走到门口，犹豫了一下，推门进去了。门吱呀响了一声。
```

### 5. 强化章末钩子
- 确保最后一句话有悬念
- 可以是：
  - 一个未解之谜
  - 一个意外发现
  - 一个危机降临
  - 一个情感高潮

章末钩子示例：
```
❌ 平淡的结尾：
张三回到家，累得直接躺在床上睡着了。

✅ 强悬念结尾：
张三躺在床上，翻来覆去睡不着。他摸出项链，却发现——项链上的宝石，正在微微发光。
```

### 6. 去AI味二次检查
- 检查是否还有AI写作痕迹
- 重点检查：
  - 过于工整的段落结构
  - 书面化的连接词
  - 缺乏人物特色的对话
  - “完美”但无聊的描写

### 7. 生成修改说明
列出所有修改之处：
```
【修改说明 - 第5章】

== 对话优化 ==
• 第3段：张三对话改为更符合内向性格的表达
• 第7段：李明对话增加神秘感

== 画面感增强 ==
• 第5段：将"张三很害怕"改为动作描写
• 第10段：增加环境描写烘托氛围

== 节奏调整 ==
• 第12-15段：精简冗长描述，加快节奏

== 章末钩子强化 ==
• 最后一段：增加项链发光的细节，制造悬念
```

## 优化原则

### 保留原意
- 不改变核心情节
- 不改变人物设定
- 不改变剧情走向

### 适度优化
- 不要过度修饰
- 保留“粗糙感”（真实感）
- 网文不需要过于精致的文学性

### 平台适配
- 起点系：可适当文艺
- 番茄系：快节奏，少铺垫
- 晋江系：重情感，重人物互动

## 注意事项
- 修改后再次进行合规审查（防止修改引入新问题）
- 如人工有具体修改要求，优先满足人工要求
- 不要为了“文笔好”而牺牲节奏和可读性

## 调用示例

**输入1**（有审查报告）：
```
根据审查报告优化第5章正文
审查问题：1. 第3段对话OOC  2. 第8段物品矛盾
```

**输入2**（人工要求）：
```
优化第5章
要求：1. 加强张三和李明的对峙感  2. 章末钩子再悬念一些
```

**输出**：
```
已优化第5章正文。

主要修改：
1. 第3段对话改为更符合张三内向性格的表达
2. 第8段修正物品矛盾（照片改为回忆）
3. 增加两人对峙时的动作和眼神描写
4. 章末增加项链发光的细节

优化后字数：2034字
是否再次进行合规审查？
```
